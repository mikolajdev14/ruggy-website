## Priority Issues

**[P1] Legal Read surface is a single unstructured <p>.** legal-document-page.tsx dumps §1–§15 into one whitespace-pre-wrap paragraph — no headings/anchors/lists. SR users can't navigate; wall of text on trust-critical page. Fix: structured sections (h2 per §, ol/ul for clauses).

**[P2] Success page breaks system at peak-end.** sukces/page.tsx uses emerald/amber/red-100 instead of --ruggy-success/yellow/error. Guaranteed-view moment looks foreign. Fix: ruggy status tokens.

**[P2] Validation errors have no field binding/focus movement.** Sticky-bar bullet list; no aria-invalid, no red border, no scroll/focus to first invalid. On mobile the field is off-screen above the bar. Fix: mark invalid fields, focus first on fail, jump-links.

**[P3] CTA verb still fragmented.** Unify reached only header + magnetic CTA; hero/process/marketing shell diverge; ink vs blue primary button. Fix: one verb spine + unified color.

**[P3] First-timer noise atop /zamow.** Returning-customer "Zapłać tutaj" banner sits above the "Krok pierwszy" hero. Fix: demote below grid or into footer.
